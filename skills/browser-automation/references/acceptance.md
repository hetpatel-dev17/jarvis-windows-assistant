## Before live adoption of the candidate

- [ ] Choose one controlled real-browser workflow with the owner.
- [ ] Ensure only one driver owns the signed-in browser at a time.
- [ ] Connect model observations and actions without duplicate Playwright/CDP attachment.
- [ ] Preserve one review for consequential submissions and no replay after uncertainty.
- [ ] Verify unknown-page button selection, input, scrolling, tabs, and completion state.
- [ ] Measure latency, stale-element recovery, repeated actions, and honest failure reports.
- [ ] Record owner acceptance before proceeding to the next development stage.

Only after browser acceptance should the ChatGPT/Claude code-extraction and CLI build stages proceed. No board or COM port is selected, opened, or flashed in this phase.
