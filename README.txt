YOUR JARVIS

Double-click Start Jarvis on your Desktop.

Type a task and press Run task.
Or press Speak. Talk. Press Finish speaking.
Spoken commands now run automatically.
Switch that option off to check the words before running a task.
Use Commands.txt for the full list of working command phrases.

First-time sign-ins:
Click Open normal sign-in browser.
Jarvis pauses its browser controls during sign-in.
Sign in to Google in the normal Chrome window. This covers Gmail and Calendar.
Sign in to ChatGPT in its tab.
Link WhatsApp using your phone and its QR code.
Close the separate sign-in browser window. Leave the Jarvis page open.
Click Finish sign-in in Jarvis.
Jarvis can then reconnect to those saved sessions.
If a site asks you to log in again, return to normal sign-in mode.
Do not ignore security warnings.
These use a separate browser profile made for Jarvis.

YouTube searches now open the results directly and wait for video results.
WhatsApp searches match contact names without depending on capital letters.
Jarvis waits for the correct chat before filling a message.
It sends only after approval, checks the outgoing bubble, and does not
automatically retry an uncertain send.

When an approval box appears, check the browser and draft.
Approve only if the action, recipient, and message are correct.
You can cancel it.

Stop task prevents further actions. Already-submitted actions cannot be undone by Stop.
Stop voice stops spoken playback.

Speech recognition uses local Whisper.

Your spoken reply text goes to ElevenLabs.
No morning schedule is enabled.

Website sign-ins, CAPTCHAs, passwords, and account changes need you.
