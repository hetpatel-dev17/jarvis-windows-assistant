# Roadmap

## Phase 1 — Connect and verify pipelines

- [x] Local model and OpenJarvis orchestration.
- [x] Local speech transcription and ElevenLabs playback.
- [x] One speech channel and duplicate-reply prevention.
- [x] YouTube search, video navigation, and volume controls.
- [x] Reviewed WhatsApp message submission.
- [x] ChatGPT prompts, history navigation, and upload plus Send.
- [x] Local filename search and chosen-result opening.
- [x] Public source repository, documentation, automated checks, and issue labels.
- [ ] Gmail authenticated reading acceptance test.
- [ ] Calendar authenticated reading acceptance test.
- [ ] Fresh Windows installation acceptance test.
- [ ] Larger-drive, offline-file, audio-device and restart recovery checks.

## Phase 2 — Refine the product

- [ ] Agree on the final interface with the owner after pipeline verification.
- [ ] Improve disambiguation from spoken folder context.
- [ ] Consider an opt-in local filename index for faster broad searches.
- [ ] Add diagnostics that describe actionable failures in simple words.

Always-on listening, changing network radios, unrestricted system execution, and automatic scheduled briefs are not currently enabled.
